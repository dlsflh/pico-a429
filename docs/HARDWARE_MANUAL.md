# ARINC 429 Pico 2 W 硬件连线与电气设计手册

本手册详细说明 Raspberry Pi Pico 2 W (RP2350) 与 ARINC 429 航空电子物理总线之间的硬件引脚定义、外部收发芯片接线、防浪涌保护以及免芯片实验室自测环回接线方案。

---

## 一、 Pico 2 W (RP2350) 核心引脚物理定义

Pico 2 W 共有 40 个物理引脚（DIP-40 封装，间距 2.54mm）。下表列出本项目 ARINC 429 通道 0 默认占用的引脚及电源地线分布：

```
                           Pico 2 W Pinout (ARINC 429 CH0)
                                    ┌─── USB ───┐
      (TX_A) GPIO 0  [Pin 1]  ───● │           │ ●─── [Pin 40] VBUS (5V 输入)
      (TX_B) GPIO 1  [Pin 2]  ───● │           │ ●─── [Pin 39] VSYS
                GND  [Pin 3]  ───● │           │ ●─── [Pin 38] GND (系统地)
      (RX_A) GPIO 2  [Pin 4]  ───● │           │ ●─── [Pin 37] 3V3_EN
      (RX_B) GPIO 3  [Pin 5]  ───● │           │ ●─── [Pin 36] 3V3_OUT (3.3V 输出)
             GPIO 4  [Pin 6]  ───● │           │ ●─── [Pin 35] ADC_VREF
             GPIO 5  [Pin 7]  ───● │           │ ●─── [Pin 34] GPIO 28
                GND  [Pin 8]  ───● │           │ ●─── [Pin 33] GND
                                   │    ...    │
                                   └───────────┘
```

### 默认引脚功能定义表 (Channel 0)

| 物理引脚 | 芯片 GPIO | 信号名称 | 方向 (相对MCU) | 内部上下拉配置 | 电气标准 | 说明 |
| :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **Pin 1** | **GP0** | `TX0_A` | 输出 (OUT) | 浮空 (None) | 3.3V CMOS | 发送通道 A 脉冲 (逻辑 1 为高) |
| **Pin 2** | **GP1** | `TX0_B` | 输出 (OUT) | 浮空 (None) | 3.3V CMOS | 发送通道 B 脉冲 (逻辑 0 为高) |
| **Pin 3** | **GND** | 地线 | - | - | 0V 电位 | **必须与收发器地共地** |
| **Pin 4** | **GP2** | `RX0_A` | 输入 (IN) | 下拉 (Pull-Down) | 3.3V CMOS | 接收通道 A 脉冲 (+10V 为高) |
| **Pin 5** | **GP3** | `RX0_B` | 输入 (IN) | 下拉 (Pull-Down) | 3.3V CMOS | 接收通道 B 脉冲 (-10V 为高) |
| **Pin 36**| **3V3** | 电源输出 | 输出 (3.3V) | - | 3.3V 最大300mA | 可供电给 3.3V 接收比较器 |
| **Pin 38**| **GND** | 地线 | - | - | 0V 电位 | 屏蔽层与电源返回地 |

## 二、 ARINC 429 物理总线特征与电平要求

ARINC 429 物理总线采用 **屏蔽双绞线 (Shielded Twisted Pair, 78 $\Omega$)** 传输差分双极性归零码（BPRZ）：

```
                    逻辑 1 (+10V)
     +10V ──┐             ┌──
            │             │
       0V ──┴──────┬──────┴──  Null (0V, 空闲与后半周期)
                   │
     -10V ─────────┘           逻辑 0 (-10V)
          |<-- 50% -->|<-- 50% -->|
```

- **逻辑 1**：前半周期 $V_A - V_B = +10\text{V} \pm 1.0\text{V}$，后半周期回到 $0\text{V} \pm 0.5\text{V}$
- **逻辑 0**：前半周期 $V_A - V_B = -10\text{V} \pm 1.0\text{V}$，后半周期回到 $0\text{V} \pm 0.5\text{V}$
- **Null (零电平/空闲)**：$V_A - V_B = 0\text{V} \pm 0.5\text{V}$ (Line A 和 Line B 均接近 0V)
- **注意**：Pico 2 W 的 GPIO 引脚绝对最大耐压为 **3.6V**。**严禁将 $\pm10\text{V}$ 总线直接接到 Pico 2 W 引脚上**！

## 三、 典型硬件方案 A：专用工业级收发芯片方案

工业和航空维修台架推荐使用 Holt 公司的集成收发芯片（或国产兼容型号）：

### 1. 发送端驱动芯片 (HI-8585 / HI-8586 / BD429)

HI-8585 将 MCU 的两路 3.3V/5V 单端数字输入转换为标准的 $\pm10\text{V}$ 差分输出：

```
 Pico 2 W                                 Holt HI-8585                 ARINC 429 Bus
┌───────────┐                         ┌───────────────────┐            Line A (HI)
│  GP0 (Pin1)├─── TX_A ───────────────┤ 1 TXINA     AOUT 4 ├──────────── [A]
│  GP1 (Pin2)├─── TX_B ───────────────┤ 2 TXINB     BOUT 5 ├──────────── [B]
│           │                         │                   │            Line B (LO)
│       GND ├─── 系统地 ──────────────┤ 3 GND        +12V 8 ├── +12V 电源
└───────────┘                         │              -12V 7 ├── -12V 电源
                                      │             +5V/VCC ├── +5V 电源
                                      └───────────────────┘
```

- **连接注意**：
  - `TXINA` 与 `TXINB` 为高电平有效。当 GP0 发出高电平脉冲时，HI-8585 在 AOUT-BOUT 之间产生 $+10\text{V}$；当 GP1 为高时产生 $-10\text{V}$；两者均为低时输出 $0\text{V}$ (Null)。
  - 若使用 3.3V 供电的派生型号（如 HI-8584/HI-8585-33），逻辑输入直接与 Pico 2 W 兼容。
  - 在 AOUT 和 BOUT 输出引脚串联两个 $37.5\,\Omega$ 匹配电阻（通常芯片内部已集成部分，外部补充至阻抗匹配 $78\,\Omega$）。

---

### 2. 接收端接口芯片 (HI-8588 / HI-8444)

HI-8588 包含差分输入衰减网络与比较器，将 $\pm10\text{V}$ 信号转为 MCU 可识别的两路 3.3V CMOS 逻辑脉冲：

```
 ARINC 429 Bus                            Holt HI-8588                Pico 2 W
  Line A (HI)                         ┌───────────────────┐          ┌───────────┐
 [A] ─────────────────────────────────┤ 1 RINA     TESTA 8│          │           │
 [B] ─────────────────────────────────┤ 2 RINB    ROUTA 7 ├─ RX_A ───┤ GP2 (Pin4)│
  Line B (LO)                         │           ROUTB 6 ├─ RX_B ───┤ GP3 (Pin5)│
                                      │ 3 GND       VCC 5 ├── +3.3V ─┤ 3V3 (Pin36)
                                      └───────────────────┘          │ GND (Pin3)│
                                                                     └───────────┘
```

- **工作电平与状态**：
  - 当总线呈现 $+10\text{V}$ 脉冲（Bit 1 前半周期）时：`ROUTA` 输出高电平（3.3V），`ROUTB` 输出低电平；
  - 当总线呈现 $-10\text{V}$ 脉冲（Bit 0 前半周期）时：`ROUTA` 输出低电平，`ROUTB` 输出高电平（3.3V）；
  - 当总线处于 Null（0V）或字间隙时：`ROUTA` 和 `ROUTB` 均为低电平（0V）。
  - 这与固件内 PIO RX 状态机的微代码采样逻辑完全吻合！

## 四、 典型硬件方案 B：实验室分立高速比较器方案 (低成本替代)

若临时没有专用 Holt 芯片，可采用常规双路高速比较器（如 **LM393** / **LM319** / **TLV3502**）：

```
                  +10kΩ         +3.3V
           Line A ──/\/\───┐     │
                          ├─── + │\
           Line B ──/\/\───┼─── - │ >─── Pull-up(4.7k) ─── GP2 (RX_A)
                  +10kΩ   │       │/
                        门限偏置   LM393 (前半部分)
```
- 通过分压网络将 $\pm10\text{V}$ 衰减至 $0\sim 3.3\text{V}$ 安全范围；
- 比较器门限设置：正向比较门限设为 $+3.0\text{V}$，反向比较门限设为 $-3.0\text{V}$，低于门限则判定为 Null；
- 输出端必须接上拉电阻至 Pico 2 W 的 3.3V。

## 五、 实验室免外置芯片“环回自测 (Loopback)”接线

在手头**没有任何外部收发芯片**的情况下，可以通过 Pico 2 W 自带引脚搭建 **3.3V 逻辑电平闭环自测试验台**：

### 环回连线图

```
      Pico 2 W 发送端                               Pico 2 W 接收端
  ┌───────────────────────┐                     ┌───────────────────────┐
  │  GP0 [Pin 1] (TX_A)   ├─── [ 220Ω 限流电阻 ] ───┤ GP2 [Pin 4] (RX_A)   │
  │                       │                     │                       │
  │  GP1 [Pin 2] (TX_B)   ├─── [ 220Ω 限流电阻 ] ───┤ GP3 [Pin 5] (RX_B)   │
  │                       │                     │                       │
  │  GND [Pin 3]          ├─── [ 直接相连 ] ──────┤ GND [Pin 8]           │
  └───────────────────────┘                     └───────────────────────┘
```

### 环回自测工作原理说明：
1. 本固件的 PIO TX 状态机输出高有效逻辑脉冲（GP0 代表 1，GP1 代表 0）；
2. 本固件的 PIO RX 状态机配置为高有效脉冲边沿检测；
3. 将 GP0 接到 GP2、GP1 接到 GP3 后，发送端发出的脉冲直接被接收端 PIO 捕获，完美模拟 ARINC 429 的 BPRZ 脉冲序列！
4. **限流电阻建议**：建议在回路中串入 $100\,\Omega \sim 330\,\Omega$ 小电阻，防止调试误配置引脚方向造成短路损坏。
